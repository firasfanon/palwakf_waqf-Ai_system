# MEGA_BATCH_ASSISTANT_STAGING_DEPLOYMENT_DISCOVERY_AND_CERTIFICATION_V1

## طبيعة الحزمة

هذه حزمة **اكتشاف وتوثيق للقراءة فقط** لمسار Staging الفعلي للمساعد. لا تنشر شيئًا ولا تعدل ملفات المصدر ولا تشغّل SQL أو قاعدة بيانات.

## لماذا هي لازمة

المصدر المحلي اجتاز TypeScript والبناء، لكن لا يوجد حتى الآن دليل موثوق يثبت:

- مزود الاستضافة الفعلي للمساعد؛
- عنوان Staging؛
- آلية النشر المستخدمة فعليًا؛
- متغيرات البيئة المطلوبة بأسماء المفاتيح فقط؛
- نقطة الرجوع (Rollback) التشغيلية.

لا يجوز افتراض أن Vercel أو Git أو أي مزود آخر هو المسار المستخدم.

## ما تجمعه

- جرد أعلى مستوى للمجلد؛
- مؤشرات ملفات النشر والبنية التحتية مع SHA-256؛
- أوامر `package.json`؛
- أسماء مفاتيح `.env` فقط، من دون القيم؛
- فهرس إشارات المحتوى بكلمات مفتاحية من دون نسخ الأسطر؛
- وجود Git وأسماء remotes فقط، من دون إظهار عناوينها.

## ما لا تفعله

```text
NO_DEPLOYMENT
NO_SOURCE_MUTATION
NO_SQL
NO_DATABASE_WRITE
NO_SECRET_EXPORT
NO_PRODUCTION_ACTION
```

## التنفيذ

بعد فك ضغط الحزمة، شغّل:

```powershell
& ".\01_RUN_READ_ONLY_DISCOVERY.ps1"
```

سيُنشئ ZIP مستقلًا في مجلد Downloads. ارفع ملف ZIP الناتج فقط.
