# Runbook — إعادة اختبار احتواء ملف المراجعة

## الهدف
إثبات أن ملف مراجعة واحد قابل للقراءة دون تداخل أو تمرير خلفي قبل بدء عينة المراجعة البشرية.

## الخطوات
1. شغّل التطبيق محليًا بعد نجاح check/build.
2. افتح `/knowledge#/admin/knowledge-review-operations`.
3. اختر مهمة **تحقق استشهاد** فقط، واضغط **فتح ملف**. لا تضغط استلام أو حفظ.
4. تحقق من:
   - عنوان ملف المراجعة ظاهر في نفس النافذة.
   - قسم سياق الوثيقة والاستشهادات ضمن مساحة واحدة قابلة للتمرير.
   - footer يحتوي إغلاق ولا يخرج خارج النافذة.
   - تمرير الفأرة فوق الخلفية لا يحرك قائمة المهام.
   - زر Escape وإغلاق النافذة يعيدان التحكم دون بقاء قفل تمرير.
5. أعد الاختبار بعرض هاتف أو نافذة ضيقة.

## قبول / رفض
- **PASS:** لا تداخل، لا تسرب، لا تمرير خلفي، جميع حقول السند قابلة للقراءة.
- **BLOCKED:** أي تراكب أو قص أو عدم إمكانية قراءة/اختيار الاستشهاد يمنع تنفيذ العينة البشرية.
