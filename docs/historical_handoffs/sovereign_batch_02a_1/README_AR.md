# Sovereign Batch 02A.1 — Review Case Modal Containment + Runtime Read Resilience

## طبيعة الدفعة
تطوير محلي محكوم لإغلاق سلامة واجهة ملف مراجعة المعرفة، وتقليل فشل قراءات الـruntime المتكرر بطريقة آمنة. لا تتضمن أي SQL، ولا تغيّر حالات مهام المراجعة، ولا تنفذ KB08B mapping أو `assistant.publish` أو إصدار معرفة.

## ما يتغير
1. **ملف المراجعة:** نافذة ذات طبقات z-index صريحة، overlay أعلى من طبقات لوحة الإدارة، مساحة محتوى مستقلة ذات تمرير داخلي فقط، footer ثابت، وقفل للتمرير في `.admin-content` أثناء فتح الملف.
2. **قراءة runtime:** عند فشل query مرافقة لازمة للسند/الملفات/الاستشهادات، يرفض الـbundle الجزئي ويرجع إلى fallback الحالي بدل إرجاع وثيقة بلا سياق أو تكرار تحذيرات `fetch failed` في كل طلب.

## ما لا يتغير
- لا تعديل بيانات Supabase.
- لا تعديل SQL/RLS/RPCs.
- لا رفع `is_chat_eligible` ولا إصدار معرفة رسمية.
- لا تغيير في منطق `assistant.review` أو `assistant.publish`.

## معيار القبول
- نافذة ملف مراجعة واحدة واضحة بالكامل دون تسرب عناصر إلى الخلفية.
- التمرير داخل جسم النافذة فقط، والـfooter ظاهر دائمًا.
- لا يمكن تمرير قائمة مهام المراجعة خلف النافذة.
- عند فشل companion read يظهر تحذير موحد محدود، ويُستخدم fallback بدلاً من bundle ناقص السند.
