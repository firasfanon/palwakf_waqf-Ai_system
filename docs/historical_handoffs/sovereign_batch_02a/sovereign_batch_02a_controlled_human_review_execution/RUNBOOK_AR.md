# Runbook — Controlled Human Review Execution (Sample of Three)

## قواعد صارمة
- استخدم حساب المراجع صاحب `assistant.review` فقط.
- لا تستخدم `assistant.publish` ولا زر إصدار.
- لا تفتح تبويب KB08B لتنفيذ قرار، فهو محجوب في هذه الدفعة.
- لا تنفذ أي قرار إلا بعد فتح **ملف المراجعة** ومراجعة العنوان والمحتوى المقيد والمصدر/الاستشهاد.
- لا تعدّل URL أو locator أو excerpt بالتخمين.

## العينة 1: content_classification
1. افتح أول مهمة `content_classification` ذات الحالة `open`.
2. اضغط **فتح ملف**، وراجع `content_status` ومعاينة المحتوى وسجل المهمة.
3. اضغط **استلام**؛ تحقق من تحول الحالة إلى `in_progress` وأن الإسناد لك.
4. اختر فقط القرار المطابق للحالة الحالية (`test` أو `duplicate` أو `quarantined`) أو `defer`.
5. اكتب سندًا تشغيليًا لا يقل عن 20 حرفًا.
6. احفظ القرار.
7. التحقق المتوقع: `is_chat_eligible=false` دائمًا؛ الحالة `completed` للقرار الاحتوائي أو `blocked` للإرجاء.

## العينة 2: source_verification
1. افتح مهمة `source_verification` ذات الحالة `open`.
2. اقرأ المرجع القانوني واسم الجهة والرابط الموجودين في ملف المراجعة.
3. افتح المصدر الأصلي خارج النظام وتحقق يدويًا من الجهة والرابط الرسمي.
4. استلم المهمة.
5. أدخل اسم الجهة والرابط القانوني النهائي فقط بعد المطابقة.
6. احفظ التوثيق.
7. التحقق المتوقع: المهمة `completed`، والمصدر `verified`، ولا يحدث release.

## العينة 3: citation_verification
1. افتح مهمة `citation_verification` ذات الحالة `open`.
2. راجع الاستشهاد المحدد في ملف المراجعة، ثم طابقه يدويًا مع المرجع الأصلي.
3. استلم المهمة.
4. اختر `citation_id` الصحيح وأدخل locator محددًا (مادة/صفحة/فقرة) ومقتطفًا مطابقًا.
5. احفظ التوثيق.
6. التحقق المتوقع: الاستشهاد `verified` والمهمة `completed`، والوثيقة تبقى غير منشورة.

## Evidence المطلوب بعد العينة
- لقطة قبل وبعد لكل مهمة تبين المرحلة والحالة وملف المراجعة.
- نتائج SQL verification كما هي.
- Network للدوال الثلاث، دون ظهور مفتاح Service Role أو وصول مباشر لجداول assistant.
- لقطة من `/knowledge#/chat` تثبت عدم وجود إصدار أو تغيير في chat eligibility.

## حالات التوقف
أوقف العينة فورًا إذا ظهر أي مما يلي:
- المهمة مسندة لمراجع آخر.
- لا يوجد مرجع/استشهاد يمكن مطابقته.
- محتوى الحالة لا يطابق قرار الاحتواء المتاح.
- أي دعوة لإصدار أو `assistant.publish`.
- خطأ قاعدة بيانات أو رفض scope غير متوقع.
