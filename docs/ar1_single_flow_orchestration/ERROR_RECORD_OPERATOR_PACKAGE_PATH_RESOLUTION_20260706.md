# Error Record — مسار حزمة التحقق

## العرض

ظهر `CommandNotFoundException` عند تشغيل سكربت التحقق من جذر المشروع، لأن سكربتات الحزمة المفكوكة ليست جزءًا من جذر المصدر.

## السبب

الخلط بين مجلد المشروع ومجلد حزمة الدفعة بعد فك ZIP.

## ما فشل

استدعاء `02_VERIFY...ps1` بصيغة `./` من داخل جذر المشروع.

## الحل

تحديد مسار سكربت التحقق داخل مجلد الحزمة المفكوكة وتشغيله باستخدام عامل الاستدعاء `&`، دون إعادة تطبيق patch.

## الحالة

تم استرداد التحقق وأظهر `STATIC_VERIFIER=PASS` و`FINAL_RESULT=PASS`. لا يوجد تعديل مصدر أو قاعدة بيانات ناتج عن هذا الخطأ.
