# Governance Surface Inventory

الحوكمة مفصولة عن صفحات الاستخدام اليومي في التنقل، وتشمل: staging evidence، audit logs، security، API keys، roles، permissions، role permissions، system settings، cache، maintenance، backup، integrations، webhooks، platform bridge، and pages classification.

مسارات العمل اليومية تبقى افتراضيًا ظاهرة؛ مركز الحوكمة يفتح بصورة مستقلة من الشريط الجانبي.
