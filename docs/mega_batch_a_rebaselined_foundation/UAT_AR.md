# UAT — Mega Batch A

## بوابات إلزامية
- لا نص عربي مشوه داخل صفحات العمل المختبرة.
- بطاقات ومودالات القراءة/الإجراء صلبة بلا تراكب أو شفافية محتوى.
- في `content_classification`: قبل الاستلام لا يظهر نموذج الحفظ؛ وبعد الاستلام يظهر قرار احتوائي فقط.
- في `citation_verification`: لا يظهر إلا نموذج توثيق الاستشهاد.
- في `source_verification`: لا يظهر إلا نموذج توثيق المصدر.
- عند اختلاف المرحلة بين القائمة والسياق يتم حجب الإجراء وإظهار رسالة عملية.
- صفحات الحوكمة تظهر فقط عند فتح مركز الحوكمة والأدلة من القائمة.
- لا SQL، لا KB08B mutation، لا Chat Eligibility Change، لا Release.
